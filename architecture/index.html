01How a number gets made

The dashed loop is the part that is genuinely an agent: it chooses its own next tool call from what the last one returned. Everything drawn in grey is deterministic code — the tools it calls and the rails it cannot argue past.

02The six stages

01
Classify the industrydeterministic

Filing text is scored against an IndustryProfile registry. Industry is data, not a code path — a new sector is a config entry, not a new branch. All four companies classify correctly from their filings with nothing hardcoded: retail, semiconductors, staffing, industrial.

02
Researchagent loop

An LLM with four tools decides its own next move. Asked for Deere's segment operating profit it read the MD&A, found only prose, pivoted to the segment note, noticed the note held Q2 not Q3, then walked back through Q3 2025 and Q3 2024 to build a seasonal series. Nothing instructed that path. Every retrieval is filtered by as_of, so a backtest cannot read the answer.

03
Three forecastersagent ×3

Same evidence, three separate contexts. The separation is the point: one agent asked for three numbers returns three correlated numbers, and an ensemble of correlated estimates is theatre.

04
Critiqueagent

An adversarial reviewer sees the numbers and the evidence but not the reasoning behind them — a critic shown the argument tends to agree with it. It checks units, basis, magnitude, direction, and profit-versus-margin confusion.

05
Reconciledeterministic

Confidence-weighted, not a flat median. Guidance quality varies enormously here: ADI guides the target quarter with a point estimate, Deere guides only the full year, Hays has published analyst consensus. Outliers beyond 35% from the median are cut to a quarter weight, because capped scoring punishes blow-ups far harder than it rewards precision.

06
Rails and workbookdeterministic

Assertions an agent cannot talk its way past: units, reporting basis, anchor period, and a clamp against observed history. The writer loads the organizer template and sets three cells. A null is never written — a blank cell scores worse than a poor guess.

05What is wrong with it

Written while the problems are still open, because a page that only lists strengths is not an architecture document.

The critic has no teeth

It correctly flags problems and nothing acts on them. The design called for a refutation to send the research agent another round; that loop was never built, so a flagged metric reaches the workbook unchanged.

Evidence depth is inconsistent

Deere returned 15 rows of history, Hays returned 2 — both for net fees, none for EPS or operating profit. Two of three Hays metrics therefore have no series to fit and no clamp to catch them. That is visible in the output: pre-exceptional operating profit came out at 25.85 against a published consensus of 43.5 with management guiding to the top of a 37–46 range.

Forecasters can drift above explicit guidance

ADI guided revenue of $3.9bn ± $100m and adjusted EPS of $3.30 ± $0.15. The run returned 4,106.50 and 3.49 — outside the guided band in both cases. A point estimate published by management should bound the forecast, not merely inform it.

Fixed: full-year guidance applied to a quarter

Deere's FY2026 net income guidance implied roughly $16.67 of annual EPS, which was being used as a quarterly anchor and forced a sensible $5.25 to $10.21. Anchors now have to match the target period; rejections are logged rather than silently dropped.

Fixed: metric labels silently dropping every value

Models returned Revenue (USDm, basis: reported) where the contract wanted Revenue, so reconciliation matched nothing and every metric resolved to null. Prompt wording was tightened and a deterministic matcher added behind it, because prompts drift and a silent null is the most expensive failure available.

Fixed: rate limits killed the first full run

Four companies running concurrently hit HTTP 429 immediately on a fresh API account. Retries now back off exponentially and honour Retry-After.

Untested

The industry framework is agnostic by construction and demonstrated across four sectors. It has never been run on a fifth, and the general fallback profile has no coverage at all. Three of the four fiscal period ends are derived arithmetically from a prior quarter end rather than read from a document that states them.
