EPS-Winners forecasting agent

A research agent reads a frozen corpus of filings and transcripts, three independent forecasters argue from the same evidence, and deterministic rails decide what reaches the workbook. Twelve metrics, four companies, four industries.

01How a number gets made

The dashed loop is the part that is genuinely an agent: it chooses its own next tool call from what the last one returned. Everything drawn in grey is deterministic code — the tools it calls and the rails it cannot argue past.

02What actually happens, in plain English

Six steps. The two labelled agent decide things for themselves; the four labelled fixed code always do the same thing, on purpose.

01
Work out what kind of company this isfixed code

A retailer and a chip maker are not forecast the same way.

Filing text is matched against a profile registry, so a new sector is a config entry rather than new code. All four classify correctly with nothing hardcoded: Home Depot as retail, Analog Devices as semiconductors, Hays as staffing, Deere as industrial.

02
Go and read the filingsagent

This is the part that genuinely thinks. It picks its own next move.

Asked for Deere's segment operating profit it read the commentary, found only prose, switched to the segment note, noticed the note held Q2 rather than Q3, then walked back through Q3 2025 and Q3 2024 to build a seasonal series. Nothing scripted that path. Every document it can see is filtered by date, so a backtest cannot accidentally read the answer.

03
Sort the evidence into four channelsfixed code

Different kinds of evidence answer different questions.

Finance is reported actuals from filings — the only audited numbers. Calls is guidance and management commentary, which never appears in a table. Cyclical is seasonality and trend, computed from the finance channel rather than read anywhere. News is external and is not in the frozen corpus, so it is reported as unavailable rather than quietly invented. If any metric has too little history to trend, the agent is sent back for exactly what is missing.

04
Three forecasters argueagent ×3

Same evidence, three separate minds, no contact between them.

One anchors to management guidance, one fits the trend across the same quarter in prior years, one weighs structural change such as disposals and acquisitions. They are kept apart deliberately: one agent asked for three numbers returns three similar numbers, and an ensemble of agreeing estimates proves nothing.

05
A critic tries to break themagent

It sees the numbers but not the arguments behind them.

A reviewer shown the reasoning tends to agree with it, so this one is given only the figures and the evidence. It checks units, reporting basis, magnitude, direction, and whether a margin has been reported where a profit was asked for.

06
Fixed rules decide what gets writtenfixed code

The last word belongs to code, because code cannot be talked round.

Where management published a range, the answer is held inside it. Anchors from the wrong period are thrown out. Values far outside anything ever reported are pulled back. Outliers lose weight, because being badly wrong once costs far more than being slightly right often. A blank is never written — an empty cell scores worse than a poor guess.

03The four evidence channels

Kept separate because they answer different questions, and because a channel that is thin or missing should be visible before it becomes a bad number rather than after.

Finance
Reported actuals

Income statement lines, segment notes and margin tables pulled from filings. The only audited figures in the system.

Calls
Guidance & commentary

Earnings calls and trading statements. Where management says what it expects — things that never appear in a table.

Cyclical — derived
Seasonality & trend

Computed from the finance channel, not read anywhere. Growth rates, direction of travel, and a naive projection to argue against.

News — unavailable
External context

Not present in the frozen corpus. Reported as unavailable rather than quietly invented; it would need a public search tool.

06What is wrong with it

Written while the problems are still open, because a page that only lists strengths is not an architecture document.

The critic has no teeth

It correctly flags problems and nothing acts on them. The design called for a refutation to send the research agent another round; that loop was never built, so a flagged metric reaches the workbook unchanged.

Fixed: the consensus nobody was reading

Hays' calls channel came back empty while the corpus plainly stated a consensus of £43.5m. Pre-exceptional operating profit was forecast at 25.85 against that. A deterministic scan now hunts consensus language directly, because the score is our error divided by Wall Street's error and that figure is too valuable to depend on an agent noticing it. Two obstacles had to be cleared: the corpus is PDF-extracted and splits numbers — £4 3.5 m is 43.5, pre -exceptional is one word — and management's steer sat elsewhere in the document. Reading “top of the £37.0–46.0m range” puts the anchor at 45.28, and the metric now lands at 45.32 rather than 25.85.

Fixed: forecasts drifting past published guidance

ADI guided revenue of $3.9bn ± $100m and adjusted EPS of $3.30 ± $0.15, and the run returned 4,106.50 and 3.49 — outside the band on both. A point estimate published by management is the tightest information available to anyone outside the company; a model landing outside it has drifted, not found an edge. Both now hold at the guided figures.

Evidence depth is still uneven

A thin metric now triggers a second, targeted research pass naming exactly what is missing. It helps but does not always succeed: Hays still returns only two historical points for net fees and basic EPS, so those two have no series to fit and no clamp to catch them. Pre-exceptional basic EPS at 0.47p against a FY2025 actual of 1.31p is the visible consequence, and the critic flags it.

Run-to-run variance

Consecutive runs of the same code on the same corpus move some metrics by several percent, because the rails only engage when the research pass surfaces the anchor that triggers them. Where a rail fires the number is stable; where it does not, the forecast wanders. The deterministic scans exist to shrink that surface, and more of the pipeline should move behind them.

Fixed: full-year guidance applied to a quarter

Deere's FY2026 net income guidance implied roughly $16.67 of annual EPS, which was being used as a quarterly anchor and forced a sensible $5.25 to $10.21. Anchors now have to match the target period; rejections are logged rather than silently dropped.

Fixed: metric labels silently dropping every value

Models returned Revenue (USDm, basis: reported) where the contract wanted Revenue, so reconciliation matched nothing and every metric resolved to null. Prompt wording was tightened and a deterministic matcher added behind it, because prompts drift and a silent null is the most expensive failure available.

Fixed: rate limits killed the first full run

Four companies running concurrently hit HTTP 429 immediately on a fresh API account. Retries now back off exponentially and honour Retry-After.

Untested

The industry framework is agnostic by construction and demonstrated across four sectors. It has never been run on a fifth, and the general fallback profile has no coverage at all. Three of the four fiscal period ends are derived arithmetically from a prior quarter end rather than read from a document that states them.
