How the system works

One cutoff date governs every retrieval. The same mechanism makes the backtest honest, makes this run reproducible after the event, and lets the agent be reused for future earnings events.

The one idea worth remembering

--as-of is a single global guard, not a filter applied at each call site. Retrieval code asks for the active guard and fails loudly when none is configured, so an unguarded read is impossible rather than merely discouraged.
